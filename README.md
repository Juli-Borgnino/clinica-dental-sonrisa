## 📋 Descripción

Sitio web completo para una clínica dental familiar ficticia. El objetivo fue crear una presencia digital cálida, accesible y profesional orientada a familias que buscan atención odontológica de confianza.

## 📁 Páginas incluidas

- **Inicio** — Hero, servicios destacados, equipo y testimonios
- **Servicios** — Detalle de cada tratamiento ofrecido
- **Nosotros** — Historia del equipo y valores
- **Contacto** — Formulario de turnos, mapa y horarios

## ⚙️ Tecnologías

- HTML5 semántico
- CSS3 con variables y diseño responsive (mobile-first)
- JavaScript puro — validación de formularios, menú mobile, animaciones

## ✨ Características

- Diseño responsive adaptado a mobile, tablet y desktop
- Formulario de contacto con validación en tiempo real
- Menú hamburger para mobile
- Animaciones suaves al hacer scroll
- Accesibilidad (ARIA, skip-link, contraste)
- SEO básico con meta tags
